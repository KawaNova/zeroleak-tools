## 2. 人間による手動確認ステップ（ブラウザでの操作手順）

ローカルサーバーが起動している状態（`http://localhost:8105/`）で、以下の手順でテストを行ってください。

### ■ Step A: CSVマスキングの確認手順
1. ブラウザで [http://localhost:8105/csv-masking/](http://localhost:8105/csv-masking/) を開く。
2. エクスプローラーから `evaluation/csv/01_employees_with_mynumber.csv` をドロップゾーンへドラッグ＆ドロップ（または「サンプルCSVを読み込む」ボタンをクリック）。
3. **カラム自動判別の確認**:
   - 「氏名」「フリガナ」「マイナンバー」「電話番号」「メールアドレス」「現住所」「生年月日」に自動でチェックが入っていることを確認。
4. **「一括マスキングを実行する」** をクリック。
5. **プレビューの確認**:
   - 処理完了（約0.01〜0.05秒）の表示とともに、テーブル上でマイナンバー（`****-****-****`）や電話番号（`090-****-5678`）が緑色で伏字化されていることを確認。
6. **ダウンロードの確認**:
   - 「マスキング済みファイルを保存」を押し、ダウンロードされたCSVをExcelやメモ帳で開いて文字化けせず保存できていることを確認。

---

### ■ Step B: PDFパスワード安全解除の確認手順
1. ブラウザで [http://localhost:8105/pdf-unlock/](http://localhost:8105/pdf-unlock/) を開く。
2. エクスプローラーから `evaluation/pdf/01_payslip_protected.pdf` をドロップゾーンへドラッグ＆ドロップ（または「サンプルPDFを読み込む」ボタンをクリック）。
3. **エラーハンドリングの確認（あえて間違える）**:
   - パスワード欄に適当な文字列（例: `wrongpass`）を入力して「解除実行」を押す。
   - ➔ 「パスワードが正しくありません」と赤枠でエラー表示されることを確認。
4. **正常解除の確認**:
   - 正しいパスワード **`test2026`** を入力し、「解除実行」をクリック。
5. **完了 ＆ ダウンロード**:
   - 約0.5〜1秒で「パスワードの解除が完了しました！」と表示される。
   - 「パスワード解除済みPDFをダウンロード」をクリック。
6. **原本比較**:
   - ダウンロードしたPDF（`..._unlocked.pdf`）をダブルクリックし、**パスワード入力を求められずに即座に開き**、印字が鮮明（300DPI相当）に再構成されていることを確認。
   - 同様に `evaluation/pdf/02_withholding_slip_protected.pdf`（パスワード: **`gensen2026`**）でも確認可能。

## 3. 「サーバー送信0バイト保証」の検証手順（F12検証）

本ツールの最重要教義である「外部通信が1バイトも発生しないこと」を自ら目視確認する手順です：

1. ブラウザで任意のツール画面を開いた状態で、キーボードの **`F12`**（または右クリック ➔ 「検証」）を押して開発者ツールを開く。
2. **「Network」（ネットワーク）タブ** を選択する。
3. 赤い記録ボタンが有効になっていることを確認し、フィルターを「すべて（All）」にする。
4. 画面上でCSVファイルやPDFファイルをドロップし、マスキングやパスワード解除・ダウンロードを実行する。
5. **検証結果の確認**:
   - **ツール実行中およびファイル処理中に、外部へのリクエスト通信（Fetch / XHR / HTTP通信）が「1件も発生しない（0件）」ことを確認できます。**
   - WiFiを切断したオフライン環境（機内モード）でも、そのまま全ての機能が動作します。

## 4. 自動化テストのワンライナー実行手順

コマンドラインから一括で復号＆マスキングの回帰テストを実行する場合は、以下のコマンドを実行します：

```powershell
node --experimental-strip-types scripts/verify_operations.mjs
```

全アサーション（CSV個人情報列抽出・マイナンバー伏字化・PDF認証解除・パスワードフリー再生成）が自動検証され、すべて `PASSED` になることを確認できます。
